# Font Awesome desktop fonts

These OpenType fonts are the Font Awesome Free 7.2.0 desktop assets used to
embed inline Markdown icons in portable document exports. They are distributed
under the SIL Open Font License 1.1; the package build includes Font Awesome's
license metadata in the generated notices.

Source: <https://github.com/FortAwesome/Font-Awesome/tree/7.2.0/otfs>

After replacing any font file, run `node scripts/generate-fontawesome-font-data.mjs`
from the repository root to refresh the browser-safe generated byte module.
