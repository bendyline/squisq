# Font Awesome desktop fonts

These OpenType fonts are the Font Awesome Free 7.3.1 desktop assets used to
embed inline Markdown icons in portable document exports. They are distributed
under the SIL Open Font License 1.1; the package build includes Font Awesome's
license metadata in the generated notices.

Source: <https://github.com/FortAwesome/Font-Awesome/tree/7.3.1/otfs>

After replacing any font file, run `node scripts/generate-fontawesome-font-data.mjs`
from the repository root to refresh the browser-safe generated byte module.

# DejaVu Sans (PDF Unicode fallback)

PDF export draws text the 14 standard PDF fonts cannot encode with DejaVu Sans,
DejaVu Sans Bold and DejaVu Sans Mono. These are not checked in here: they come
unmodified from the pinned `dejavu-fonts-ttf` devDependency, and the formats
build copies that package's license (Bitstream Vera and DejaVu) into the
generated notices.

After changing the pinned version, run `node scripts/generate-unicode-font-data.mjs`
from the repository root to refresh `../unicodeFontData.generated.ts`, which the
PDF writer imports only for a document that needs it.
